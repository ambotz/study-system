# Where you write

This folder is the only place you type a practice answer. One file per rep,
already loaded with the prompt and the budget, so there is nothing to set up —
open it, start a timer, write.

## The combined rep — 15 minutes

| | |
|---|---|
| 3 min | read the prompt |
| 4 min | outline — gates in order, a holding on each, words budgeted |
| 7 min | write the opening only, ~150 words |

Then stop. Do not write the body. Do not tidy anything.

The outline and the opening get graded separately, on different axes, against
the same prompt. Axes 2, 3 and 6 are settled before a word is written; axes 1
and 5 only exist on the page. **The gap between the two is the finding.** Where
the outline named a clean holding and the prose lost it, the problem is
transcription. Where the outline was already a topic list, more writing practice
will not help.

## The triage rep — 10 minutes

Whole paper, allocation only. Read all three questions, note the weights, write
a word budget per question and per part. Then stop. Baude's ratio has been a
constant **35 words per point**, and his weights move every year, so read them
off the page rather than reusing last year's.

## Rules

- **Closed book.** No casebook, no outline, no vault, no Claude. Both exams are closed-book and a chat window is a lookup device.
- **Stop at the buzzer**, mid-sentence if that is where you are. A rep that ran long measures nothing.
- **Do not edit afterwards.** The defect is the data.

## Then

Open a Cowork session — a fresh one, not one full of doctrine talk, because the
two professor profiles have inverted polarity — and say *grade today's reps*.
`essay-grade` scores each file, writes the graded attempt into
`conlaw/60-drills/attempts/` and appends a row to `error-log.md`.
`99-exam-writing/Rep tracker.md` shows the trend.

Batch it. Write the whole sitting, then hand over all the files at once.
